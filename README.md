# 🚀 Project Overview

Stock Portfolio Tracker is a modern web-based application developed using Python Flask. This application helps users calculate the total value of their stock investments by entering stock symbols and quantities. The project provides an interactive dashboard with a clean and attractive user interface.

This project was developed as part of the **CodeAlpha Python Programming Internship**.

# ⚙️ Installation Guide

## Step 1: Clone the Repository

```bash
git clone https://github.com/YourUsername/CodeAlpha_Stock_Portfolio_Tracker.git
```

---

## Step 2: Navigate to Project Directory

```bash
cd CodeAlpha_Stock_Portfolio_Tracker
```

---

## Step 3: Install Required Packages

```bash
pip install flask
```

---

## Step 4: Run the Application

```bash
python app.py
```

# 📋 How to Use

### 1️⃣ Enter Stock Symbol

Examples:

* AAPL
* TSLA
* GOOGL
* MSFT
* AMZN

### 2️⃣ Enter Quantity

Example:

```text
10
```

### 3️⃣ Click Calculate Button

The application will calculate the total portfolio value based on the predefined stock prices.

---

# 📊 Example Calculation

### Input

```text
Stock Symbol : AAPL
Quantity     : 10
```

### Calculation

```text
AAPL Price = $180
Quantity = 10

180 × 10 = $1800
```

### Output

```text
Total Portfolio Value = $1800
```
